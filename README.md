# VertexMind Frontend Development Internship – Mission 1

## Project Overview

This project is a responsive landing page developed as part of the VertexMind Frontend Development Internship (Mission 1).

The webpage is built using HTML5 and CSS3, following responsive web design principles with Flexbox and media queries.

## Features

- Responsive Navigation Bar
- Hero Section
- About Section
- Services Section
- Contact Section
- Footer
- Mobile-Friendly Design
- Clean and Semantic HTML5 Structure

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Media Queries

## Folder Structure


## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
